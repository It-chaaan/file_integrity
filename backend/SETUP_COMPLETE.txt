================================================================================
                        TROUBLESHOOTING
================================================================================

Problem: ImportError: No module named 'psutil'
Solution: pip install -r requirements.txt

Problem: GPU monitoring not working
Solution: 
   - Check NVIDIA drivers: nvidia-smi
   - Install pynvml: pip install pynvml
   - Or simply use without GPU (still works)

Problem: validate_monitoring_setup.py fails
Solution:
   - Check Python >= 3.8: python --version
   - Reinstall requirements: pip install -r requirements.txt
   - Check all packages: pip list

Problem: Inconsistent timing measurements
Solution:
   - Close other applications
   - Test when system is idle
   - Average multiple runs
   - Check for background processes

Problem: Can't find the files
Solution:
   - All files are in backend/ directory
   - Run: cd backend
   - Then run the scripts
